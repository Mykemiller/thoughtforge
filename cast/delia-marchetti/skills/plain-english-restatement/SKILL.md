# plain-english-restatement

Persona skill for Delia Marchetti. Restate the panel's technical answer in two sentences a county commissioner would understand.

## Procedure

1. Read the ruling and the strongest supporting claim.
2. Write sentence one: what is happening, in words with no jargon.
3. Write sentence two: what it means for the person listening.
4. Replace every acronym with the plain word, or cut it.
5. Check that no number changed meaning in translation.

## Output

```
Plain version: <two sentences>. Removed jargon: <list>.
```

## Never

- Use an acronym without its plain word.
- Soften a number to make it friendlier.
- Name a real person in user-facing dialogue (TF-DEC-13).
