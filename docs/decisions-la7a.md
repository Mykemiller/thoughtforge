# FDY-345 (LA-7a) decisions log: /api/panel bridge

One plain-English sentence per decision. Choices where the issue left room, and the places this build differs from it.

- **Layout.** The handler lives in `src/panel/handler.ts` (plain `Request` in, `Response` out) and `app/api/panel/route.ts` only declares `runtime`, `maxDuration`, `dynamic` and delegates, so the route is testable without Next.
- **Auth is the first thing that runs.** Missing `LA_PANEL_TOKEN` answers 503 with a short JSON body; a missing or wrong token answers 401 with an empty body and a `WWW-Authenticate: Bearer` header; the body is never read before the token passes. Comparison is `queryKeyMatches` (SHA-256 of both sides, constant time).
- **The path stays outside the access gate.** `/api/panel` is not in `GATED_PREFIXES` and not in `proxy.ts`'s matcher; a test asserts both.
- **Validation answers 400 with `{error, issues:[{path,message}]}`.** The paths are field names only, never values, so a bad body cannot echo content back.
- **`convene` ignores `panelists`; `settings` is optional in both modes.** Only `join` requires and validates `panelists` (1 to 4, unique, from `INVITABLE`); `mach-eigen` and `gilbert-faraday` are rejected there with 400.
- **Extra field caps beyond the issue's.** `title` 300, `publisher` 200, `url` 2,000, `date` 40, `speaker` 80 and `lens` 200 characters; `url` is not format-checked because Live Agent passes through whatever the record carried. `horizon` must be an integer 0 to 4.
- **Join prompt: `settings` reach the model as turn instructions.** `lens` is passed as a framing hint that "never changes the rules above", and `horizon` as "N of 4" with the sentence that no setting lowers the citation standard and every forward sentence stays in `{{read}}`. The issue did not say how settings enter the prompt; this is the smallest faithful reading of its Horizon rule.
- **Join retrieval excerpts stay capped at 300 characters** because `retrievedBlock` already caps them and `ask`/`podcast` must stay byte-identical; the 800-character input cap is for the caller's convenience, not a longer prompt.
- **`retrievedBlock` gained an optional second argument (mode).** Only `join` changes the intro line; `ask` and `podcast` output is byte-identical to `main` (sha-256 over every cast member x {ask, podcast, default} x {no artifacts, artifacts} matched before and after).
- **A join panelist's failure or refusal is one tag-free in-voice line.** `runPanel` writes `[Name could not reply: <error>] [INF]`, which would put bracket tags and raw upstream error text into a user-facing stream and contradict the join contract, so join says "<Short name> couldn't weigh in just now." (error) or "<Short name> would rather sit this one out." (refusal) and logs nothing user-visible.
- **Constance grades through the same machinery, with join-shaped rules.** She runs the non-streaming call (`LIMITS.factcheckMaxTokens`, no `thinking`, `parseFactcheck`) with a `JOIN_FACTCHECK_TURN` that explains `{{c:n}}` and `{{read}}`; her system prompt keeps the `ask` contract (turn instructions override it, exactly as in `runPanel` stage 2) because the join contract's "reply in 120 words" would contradict a JSON-only answer.
- **"Last host turn" means the last conversation turn whose speaker is not `user` (case-insensitive).** The issue does not define speaker values; Live Agent's hosts are its own, so everything that is not the user counts as host. With no such turn she grades only the replies.
- **Grader slugs are `host` plus the speaking panelists.** `parseFactcheck` therefore accepts `panelist: "host"` and one verdict per slug; items with an unknown panelist are dropped as usual.
- **Per the issue, `tag_given` is `INF` when a claim carried no citation.** Because `parseFactcheck` drops items whose given and should-be tags are equal, an uncited claim only becomes an item when the grader says it should be something else (for example an unmarked forecast, which should be `EST` at best); an uncited plain claim is covered by the one-line verdict instead.
- **Nothing to grade means no model call.** Constance alone with a conversation that has no host turn emits an empty `factcheck` event (no `degraded` flag, because nothing failed).
- **A failed grader is `degraded` with `reason: api_error` and no upstream text.** `runPanel` interpolates the raw error into the verdict; join does not.
- **`done` for `join` is emitted by the handler after `runJoin`, with a fresh uuid.** Join sessions are not saved, so there is no `saved` event; `convene` gets `saved` then `done` from `runLive` unchanged.
- **A missing `ANTHROPIC_API_KEY` emits the exact `error` + `done` pair `/api/ask` emits** (including its message text, which is for the Live Agent operator, not a user; Live Agent must not surface `error` messages verbatim).
- **One call per conversation uses `acquire`/`release` keyed `la:<conversation_id>`.** It is process-local like `/api/ask`'s lock, so it guards one serverless instance, not the fleet; released in `finally` and in `cancel()`; `req.signal` is passed to every model call.
- **`TF_MOCK=1` replays `fixtures/panel/{join,convene}.sse` regardless of the request's panelists or question.** The files were not captured from a live run (no key in this session): `scripts/make-panel-fixtures.ts` drives the real handler end to end against a scripted stand-in for the model (`src/panel/testkit.ts`) and writes the exact wire format. The `convene` file is the existing mock session re-keyed to `la:` artifact ids. Both carry a fixed `session_id`. Regenerate with `npx tsx scripts/make-panel-fixtures.ts`; LA-7b copies the two files verbatim.
- **Prompt snapshot excludes the cast dossier.** `src/panel/__snapshots__/join-prompt.txt` holds the join-specific tail (contract, numbered retrieval, turn instructions), the user message and the grader turn, so unrelated cast edits cannot break it; refresh with `UPDATE_SNAPSHOT=1`.
- **Not done here (for Live Agent / LA-7b, listed in the PR):** nothing server-side rewrites or validates `{{c:n}}` markers in streamed text, so Live Agent must drop any `n` outside 1..k itself; a cross-instance lock would need a database row.
